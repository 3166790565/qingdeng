书源接口

四个只读 JSON 接口，统一返回 {"isSuccess": true, "data": ...}。

接口说明
GET /api/search?key=&page=书名与作者模糊匹配
GET /api/book/{id}详情，含最新章节
GET /api/book/{id}/catalog?page=目录（id、title、url，多页时给 nextUrl）
GET /api/chapter/{id}章节正文，段落以 \n 分隔纯文本

导入书源

开源阅读 → 书源管理 → 右上角 → 网络导入，地址填：

{{ .BaseURL }}/legado/源.json

这个地址按服务端当前的 SITE_BASE_URL 与 API_TOKEN 实时生成，不用手改。 {{ if .HasToken }}当前已启用 API token，书源 URL 会自动带上同一个 token 参数。{{ else }}当前未设置 API token，接口公开。{{ end }}
